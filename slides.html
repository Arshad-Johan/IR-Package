SLIDE 2 CONTEXT & MOTIVATION

Problem Statement: The Choice Overload Paradox

The 90-Second Rule

Industry behavioral metrics show that the average streaming subscriber gives up and turns off the screen if nothing catches their eye within 60 to 90 seconds.

  • Catalog Size: 40,000+ movies & episodes.
  • Screen Real Estate: Only 8–12 titles visible simultaneously without scrolling.
  • User Intent: Exploratory, subjective, and mood-driven.

Why Conventional Keyword Search Fails

  • 75%+ of views come from recommended carousels, not explicit search queries.
  • Vocabulary Mismatch: A user thinking of *"mind-bending suspense like Inception"* won't find *Shutter Island* through keyword matching alone.
  • Latency Mandate: Suggestions must be generated and rendered in < 50 ms across concurrent active sessions.
SLIDE 3 THEORETICAL FOUNDATION

Search → Recommendation: The Paradigm Shift

TRADITIONAL SEARCH (PULL)

Explicit Query Formulation

User knows their target information need and formulates a query string.

q ∈ Text Queries → Inverted Index → Static Ranked List
  • Static document ranking
  • Identical results for identical queries across different users
  • Fails when user cannot articulate target
RECOMMENDATION (PUSH)

Implicit Latent Query

System continuously infers the user's information need without explicit typing.

q_latent = {Watch History, Time, Device} → Personalized Recs
  • Proactive information retrieval
  • Dynamically tailored to each individual profile
  • Shared Goal: Optimizing relevance metric over item catalog D
SLIDE 4 IR FORMULATION

Why Information Retrieval (IR)?

1. Items as Documents

Each movie $d \in \mathcal{D}$ is an unstructured + structured document comprising title, plot synopsis, cast, director, and reviews.

2. Graded Relevance

Relevance is non-binary. IR provides probabilistic ranking functions: $P(\text{Relevant} \mid u, d)$ and learning-to-rank loss objectives.

3. Mathematical Rigor

Evaluation relies on standard IR bench metrics: Precision@K, Recall@K, Mean Reciprocal Rank (MRR), and NDCG@K.

The IR Ranking Formalism

Given user profile $\mathbf{q}_u$ and item collection $\mathcal{D} = \{d_1, d_2, \dots, d_N\}$, retrieve top-$K$ items maximizing:

d^* = \arg\max_{d \in \mathcal{D}} \text{Score}(\mathbf{q}_u, d) \quad \text{subject to } \text{Latency} \le 50\text{ms}
SLIDE 5 ALGORITHMIC FOUNDATION

Content-Based Recommendation Approach

Feature Vector Extraction

  • Text Synopses: 384-dimensional dense semantic embeddings using Sentence-BERT (MiniLM-L6-v2).
  • Categorical Attributes: One-hot and TF-IDF encoding on Genres, Directors, Cast, and Keywords.
  • Item Vector: $\mathbf{v}_i = [\mathbf{v}_{\text{semantic}} \parallel \mathbf{v}_{\text{meta}}]$.

User Profile & Scoring

The user profile $\mathbf{u}$ is the centroid of vectors of movies the user previously completed or rated highly:

\mathbf{u} = \frac{1}{|H_u|} \sum_{i \in H_u} w_i \cdot \mathbf{v}_i

Candidate items are ranked via Cosine Similarity:

\text{sim}(\mathbf{u}, \mathbf{v}_j) = \frac{\mathbf{u} \cdot \mathbf{v}_j}{\|\mathbf{u}\|_2 \|\mathbf{v}_j\|_2}
SLIDE 6 CRITICAL EVALUATION

Content-Based: Advantages & Limitations

Advantages

  • Zero Item Cold-Start: Newly ingested movies can be recommended instantly without waiting for user ratings.
  • High Explainability: Directly generates intuitive rationales: "Because you watched Interstellar..."
  • User Independence: Completely isolated; unaffected by malicious rating attacks or niche tastes.

Limitations

  • The Filter Bubble (Overspecialization): Zero serendipity; cannot discover unexpected genres the user might love.
  • Quality Blindness: A poorly rated amateur Sci-Fi film has identical keyword vectors to *Blade Runner 2049*.
  • User Cold-Start: Completely useless for brand new subscribers with an empty watch history.

SLIDE 7 CROWD INTELLIGENCE

Collaborative Filtering (CF)

The Core Axiom

"Users who agreed in the past will agree in the future."

Collaborative Filtering abandons item descriptions entirely. It learns solely from the collective interaction patterns of the user base.

The Interaction Matrix $R \in \mathbb{R}^{M \times N}$

  • Explicit Feedback: Star ratings, thumbs-up / thumbs-down.
  • Implicit Feedback: Watch completion percentage, pause rate, watchlist additions.
  • Key Asset: Naturally captures unobservable qualities like cinematography, pacing, and emotional resonance.
SLIDE 8 TAXONOMY OF CF

Types of Collaborative Filtering

1. MEMORY-BASED (NEIGHBORHOOD)

K-Nearest Neighbors

  • User-User CF: Finds users with correlated taste using Pearson correlation.
  • Item-Item CF: Finds items frequently consumed together. Industry standard due to stability ($N_{\text{items}} \ll M_{\text{users}}$).
\text{sim}(i, j) = \frac{\sum_{u} (r_{u,i} - \bar{r}_u)(r_{u,j} - \bar{r}_u)}{\sqrt{\sum_u (r_{u,i} - \bar{r}_u)^2} \sqrt{\sum_u (r_{u,j} - \bar{r}_u)^2}}
2. MODEL-BASED (LATENT FACTORS)

Matrix Factorization (SVD / ALS)

Decomposes sparse rating matrix $R \approx U \cdot V^T$ into $k$ latent dimensions (e.g., $k=100$).

\min_{U, V} \sum_{(u,i) \in R} (r_{ui} - \mathbf{p}_u^T \mathbf{q}_i)^2 + \lambda (\|\mathbf{p}_u\|^2 + \|\mathbf{q}_i\|^2)
  • Captures implicit thematic concepts (e.g., "dark noir", "indie humor").
SLIDE 9 CRITICAL EVALUATION

Collaborative Filtering: Strengths & Limitations

Strengths

  • Serendipity & Novelty: Discovers cross-genre gems that content analysis could never predict.
  • Quality Sensitivity: Masterpieces organically float to the top; flops naturally sink.
  • Domain Agnostic: Requires no textual metadata, natural language processing, or manual tagging.

Limitations

  • Severe Cold-Start: Fails completely on new items (0 ratings) and new users (0 history).
  • Extreme Matrix Sparsity: In realistic streaming catalogs, $>99.5\%$ of cells are unobserved.
  • Popularity Bias: Long-tail cinema remains starved of exposure in favor of blockbusters.
SLIDE 10 STRUCTURED LOGIC

Knowledge-Based Recommendation

Domain Ontologies & Knowledge Graphs

Treats the movie universe as an interconnected graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$:

  • Nodes: Movies, Actors, Directors, Studios, Franchises, Awards.
  • Edges: Directs, BelongsToFranchise, InfluencedBy.
  • Enables graph-traversal recommendations (e.g., all Oscar-nominated cinematographers who worked with Denis Villeneuve).

Constraint-Satisfaction Systems

  • Explicit specifications: "Find a PG-rated comedy under 100 minutes released after 2018."
  • Zero Cold-Start: Needs neither user history nor community ratings.
  • Ideal Use Case: Kids profiles, holiday curation, and explicit query filters.
SLIDE 11 DYNAMIC REALITY

Context-Aware Recommendation

1. Temporal Context

Hour & Day: Lunch breaks favor 20-min sitcoms; Friday night favors 2.5-hour cinematic thrillers.

2. Hardware & Device

Screen & Audio: Mobile phones indicate commuter viewing; 4K OLED TV indicates group/family sessions.

3. Session Dynamics

Recent Intent: Did the user just skip 3 comedies? Adapt current session weights in real-time.

Context Integration Strategy

Extending standard rating prediction with contextual tensor $\mathcal{C}$:

\hat{r}_{u, i, c} = f(\mathbf{p}_u, \mathbf{q}_i, \mathbf{c}_{\text{context}}) \quad \text{where } c \in \{\text{Time, Device, Day, Session}\}

SLIDE 13 THE HYBRID SYNTHESIS

Hybrid Recommendation Systems

The Hybrid Principle

Combine multiple recommendation algorithms so that the unique strength of one cancels the vulnerability of another.

\text{Final Score}(u, i) = \alpha \cdot S_{\text{Content}}(u, i) + (1-\alpha) \cdot S_{\text{Collab}}(u, i)

Hybridization Architectures

  • Weighted Hybrid: Linear combination of scores from distinct engines.
  • Switching Hybrid: Dynamic rule switches to Content-based when user/item is new.
  • Cascade / Multi-Stage: Broad high-recall filter followed by high-precision ranker.
  • Feature Augmentation: CF latent factors fed as inputs to a Gradient Boosted Decision Tree (GBDT).
SLIDE 14 STREAMING REQUIREMENTS

Why Hybrid for Streaming (The Netflix Model)?

1. Day-1 Catalog Ingestion

Netflix releases hundreds of exclusive originals each month. Content-Based semantic vectors ensure they are recommended within seconds of release.

2. Global Taste Communities

Collaborative latent factors cluster users into 2,000+ taste micro-communities across borders without relying on crude geographical labels.

3. Session Agility

Contextual re-ranking reshuffles the presentation grid based on whether you opened the app on a tablet or an Apple TV 4K.

SLIDE 15 ARCHITECTURAL BLUEPRINT

Proposed IR Pipeline: Two-Stage Architecture

STAGE 1: RETRIEVAL

Candidate Generation

50,000+ Titles → Top 500

  • Dense: FAISS HNSW on Sentence-BERT (384-d).
  • Sparse: BM25 on actors, plot, and director.
  • Collaborative: Latent factor item lookups.
  • Latency: < 15 ms.
STAGE 2: SCORING

Learning-to-Rank

Top 500 → Top 50

  • Model: LightGBM Ranker / LambdaMART.
  • Features (40+): Completion %, recency, popularity, similarity scores.
  • Optimizes Graded Relevance (NDCG).
STAGE 3: RE-RANKING

Diversity & Carousel

Top 50 → Display Grid

  • MMR: Maximal Marginal Relevance to eliminate genre duplication.
  • Context Filter: Time/Device gating.
  • Generates themed UI rails ("Top Picks for Alex").

SLIDE 17 IMPLEMENTATION STACK

Final Approach Selection & Tech Stack

Selected Architecture

Two-Stage Cascade Hybrid Recommender combining Approximate Nearest Neighbors vector search with Gradient Boosted Learning-to-Rank.

  • Balances high recall (never misses relevant titles) with precision ranking.
  • Guarantees sub-30ms P99 inference latency.

Technology Stack

  • Vector Indexing: FAISS / HNSW with Sentence-BERT (`all-MiniLM-L6-v2`)
  • Collaborative Engine: Scikit-Surprise / Implicit (Truncated SVD / ALS)
  • Scoring Ranker: LightGBM with LambdaMART objective
  • Serving Layer: FastAPI (Async Python) + Redis Cache
  • Presentation UI: Streamlit / React Netflix-style UI
SLIDE 18 IMPACT & ROADMAP

Expected Outcomes & Future Scope

Evaluation Framework

  • NDCG@10 > 0.72: Measures high ranking quality of top recommendations.
  • Recall@50 > 0.85: Ensures candidate generator captures true likes.
  • Intra-List Diversity (ILD): Prevents repetitive recommendations.
  • P99 Latency: < 35 ms end-to-end response time.

Future Horizons

  • Multi-Modal Artwork Personalization: Using CLIP embeddings to personalize movie thumbnail posters based on user tastes.
  • Reinforcement Learning / Bandits: Contextual multi-armed bandits for real-time explore/exploit of new catalog items.
  • Graph Neural Networks (GNNs): PinSage-style graph convolutions on relational entity graphs.
